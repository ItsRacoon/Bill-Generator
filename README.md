# Professional Bill Generator

A modern, feature-rich bill/invoice generator with professional PDF output and advanced functionality.

## 🚀 Features

### Core Functionality
- **Professional PDF Generation**: High-quality PDF invoices with proper formatting
- **Dynamic Item Management**: Add/remove items with real-time calculations
- **Smart Calculations**: Automatic subtotal, discount, tax, and grand total calculations
- **Invoice Numbering**: Auto-generated unique invoice numbers
- **Template System**: Save and load business information templates

### User Interface
- **Modern Design**: Clean, professional interface with gradient backgrounds
- **Responsive Layout**: Works perfectly on desktop, tablet, and mobile devices
- **Real-time Preview**: Preview invoices before generating PDF
- **Form Validation**: Comprehensive validation with helpful error messages
- **Toast Notifications**: User-friendly success/error notifications

### Business Features
- **Business Information**: Store and reuse business details
- **Client Management**: Comprehensive client information fields
- **Flexible Pricing**: Support for quantity, unit price, and total calculations
- **Discount System**: Percentage-based discounts with visual feedback
- **Tax Calculation**: Configurable tax rates (default: 18% GST)
- **Due Dates**: Set payment due dates
- **Notes Section**: Add terms, conditions, or special instructions

### PDF Features
- **Professional Layout**: Corporate-style PDF with branded headers
- **Detailed Tables**: Clean, organized item tables with proper alignment
- **Color Coding**: Professional color scheme with primary brand colors
- **Comprehensive Information**: All business and client details included
- **Calculation Breakdown**: Clear display of subtotal, discounts, taxes, and totals
- **Metadata**: Generated date and thank you message

## 🔧 Setup and Usage

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection (for external libraries)

### Installation
1. Download all files to a local directory
2. Open `index.html` in a web browser
3. Start generating professional invoices!

### Usage Guide
1. **Business Information**: Fill in your business details (saved as template)
2. **Client Information**: Enter client details
3. **Add Items**: Add products/services with quantity and pricing
4. **Configure Taxes**: Set discount and tax percentages
5. **Set Dates**: Choose bill date and due date
6. **Add Notes**: Include payment terms or special instructions
7. **Preview**: Review the invoice before generating
8. **Generate PDF**: Create and download professional PDF

## 🔒 Data Privacy
